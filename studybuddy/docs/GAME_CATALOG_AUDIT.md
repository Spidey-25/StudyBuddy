## Coverage notes

- The browser-local catalog has 66 cards. Unit checks confirm each card maps to its own mode and has a populated, valid content bank.
- The platform catalog has 32 cards. MySQL integration starts each catalog ID and checks lifecycle, ownership and exact-once completion/reward behavior.
- Python Logic Builder has 12 authored tasks across Easy, Medium, Hard and Expert; its session order is randomized within difficulty and avoids repeating the prior run’s last task first.
- Code-edit answers are checked against private deterministic fixtures. Learner source is not compiled or executed.
- Browser smoke test opened C Code Builder from its catalog card, verified its reordering controls and distinct title, toggled Save on and off, exited it, and verified the session status was `abandoned`.
- Browser smoke test opened C++ Code Debugger from its own card, verified the code-edit interface, used browser Back, and confirmed the platform session appeared in History as `abandoned`.
- Search for SQL Query Lab, the DBMS subject filter, game-type filter, and completed-status filter were checked in the browser; Clear filters restored all 98 cards.
