Optional real photos for the floating welcome-page cards.
Put image files here with these exact names (portrait, about 600 x 750 px, JPG):

  dbms.jpg  dsa.jpg  os.jpg  networks.jpg  python.jpg  ml.jpg
  happy-students.jpg   (people enjoying learning together)
  learning-tech.jpg    (laptops, tablets, VR or other learning technology)

If a file is missing the card shows its drawn illustration instead.
Use photos you have the right to use (for example from sites that offer free-to-use images, and follow their licence).
Open index.html from a folder or local server so the images/ path resolves.
